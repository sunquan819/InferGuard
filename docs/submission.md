# 初赛提交草稿

## 项目名称

**InferGuard：AI 推理服务零人工自愈**

## 作品简介（500 字以内）

企业部署大模型推理服务后，故障信号分散在 AI 网关、推理引擎、GPU、Kubernetes、Trace 与质量评测系统中。传统 AIOps 往往只能判断基础设施是否存活，难以识别模型灰度、KV Cache、路由与回答质量之间的关联，也容易把“命令执行成功”误判为“业务恢复”。InferGuard 面向 AI 平台与 SRE 团队，以 AgentTeams 为协同基点，由事故指挥、信号分析、根因调查、安全治理、修复执行、恢复学习六类 Agent 组成闭环。系统将多源告警归并为结构化事故，以证据引用和反证对根因排序；低风险、白名单、可逆动作可自动执行，高风险动作进入人工审批；修复后由独立 Agent 同时验证错误率、TTFT 和回答质量，失败即回滚，并生成事故复盘与 Runbook。当前已完成无外部密钥的可运行 PoC，能回放模型灰度导致 KV Cache 争用的事故，输出 9 个结构化 Trace 事件、修复证据和复盘报告，并通过自动化安全测试。项目计划以 Apache-2.0 开放 Agent Identity、核心 Skill、MCP 契约、仿真事故数据集与评测工具，后续接入 Higress、vLLM、Kubernetes 和 AgentLoop。

## 当前进展证据

- 完整本地闭环可运行。
- 7 条告警归并为 5 个唯一信号和 1 个事故。
- Top-1 根因命中标注，当前置信度 0.89。
- 回切后错误率、p99 TTFT、回答质量三项 SLO 通过。
- 非白名单高风险动作由自动化测试拦截。
- 输出结构化 `incident.json` 和 `postmortem.md`。
